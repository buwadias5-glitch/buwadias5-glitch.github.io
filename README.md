## About this project

This is my personal e-portfolio. It presents my education, leadership roles, projects, awards, skills and contact details in one place, and includes a downloadable PDF of my resume. It was built as a take-home assignment using GitHub, Markdown and HTML, and it is published with GitHub Pages.

## Sections

1. About me
2. Education and professional qualifications
3. Leadership roles
4. My projects (biotechnology projects and community projects)
5. Awards
6. Skills (technical, laboratory, languages, personal)
7. Hobbies
8. Resume (PDF download)
9. Contact details

## Built with

- **HTML5** for the page structure
- **CSS3** for the layout, colours, icons and responsive design (it adapts to phones and computers)
- **Markdown** for this documentation
- **GitHub** and **GitHub Pages** for version control and hosting
